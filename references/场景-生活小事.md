# 场景:生活小事

默认场景。漏斗没命中别的场景、学生也没明说时,就练这个。

| 字段 | 内容 |
|---|---|
| 对象 | 朋友、家人 |
| 目的 | 按 `references/题源.md` 四类:推荐(让对方想去试)、解释(让没经历过的人听懂)、讲事(让对方听完有画面)、表态(让对方知道你的立场和原因);真实复盘按当时想达到的目的 |
| 时长 | 默认 60 秒,上限 90 秒 |
| 默认结构卡 | 按题型选,见 `references/结构卡.md`:推荐 K1/K2、解释 K3、讲事 K4、表态 K5,`references/题源.md` 里每题标的卡优先;第三遍听众追问不发卡,K7 只是老师判断他答得直不直接的参考 |
| 追加评分项 | 无 |
| 题源 | `references/题源.md` 四类;不需要学生提供素材 |
| 听众角色 | 「朋友」:只问 1 个朋友真会问的问题,如贵不贵、远不远、你去过几次 |
| 新手档上限 | 一张卡 + 空塔 + 原句素材表 |
| 不做 | 不编没发生的事 |
