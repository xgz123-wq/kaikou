# 场景模板

加一个场景=加一个文件,引擎不动;每个场景一页以内。

复制下面这段,存成 `场景/场景名.md`,每个字段填一句到几句。

```
# 场景:XX

| 字段 | 内容 |
|---|---|
| 对象 | 讲给谁听 |
| 目的 | 听完要他做什么/信什么 |
| 时长 | 默认几秒,上限几秒 |
| 默认结构卡 | 结构卡的编号,按题型选,每个题型最多 2 张;题源里每题标的卡优先 |
| 追加评分项 | ≤2 项,0/1,写清得 1 标准 |
| 题源 | 这个场景从哪出题;需要学生提供什么素材 |
| 听众角色 | 第三遍追问时老师扮谁、问什么类型的问题 |
| 新手档上限 | 这个场景老师最多可以给到什么 |
| 不做 | 这个场景的红线 |
```

- 追加评分项只在该场景内比,不加进核心 6 项的满分。
- 学生要提供的素材放 `学生档案/素材/`,场景包里只写要什么,不存学生的东西。
